    Tool list¶

    Current tools defined in tools.py and playwright_tools.py and registered by server.py, grouped by capability. The default KITSUNE_CAPS=core exposes the 27 core tools: Playwright MCP's 25 core tools with the same definitions (Core tools), browser_resume and browser_ask_user. KITSUNE_CAPS=all exposes all 97. Set a comma-separated list to enable selected groups, for example KITSUNE_CAPS=core,browse,read. The storage and history groups are not part of all: they read personal data and must be named, as in KITSUNE_CAPS=all,storage,history. Calling a tool that is not published returns tool_not_published naming the setting (API reference). With KITSUNE_PUBLISH set to fewer groups, tools/list starts with those and the gateway tools below reach the rest (Finding tools without a restart).

    These counts describe the default KITSUNE_MODE=act. KITSUNE_MODE=read|draft further intersects the capability surface and enforces the same limits on bridge calls; see Task modes. With core:

    • read (9): browser_tab_list, browser_navigate, browser_snapshot, browser_find, browser_wait_for, browser_console_messages, browser_network_requests, browser_network_request, browser_ask_user.
    • draft (12): read plus browser_type, browser_select_option, browser_fill_form.
    • Other enabled groups contribute only read tools (browse adds browser_scroll and, for draft, browser_check). Restricted modes replace multi-action browser_tabs with browser_tab_list, which lists tabs and opens background tabs (new_tab) but cannot close or select them, and omit clicks, submit, JavaScript, screenshots/file writes, policy changes and containers. Draft refuses sensitive/payment-like fills without issuing confirmation tokens.

    See the API reference for parameters and behavior.

    browser_emulate_media and browser_run_code_unsafe are listed for compatibility and answer not_supported. browser_resume is Kitsune's: it continues a direct call that stopped on needs_user, or a container call that did not finish ok (Checkpoint and resume). So is browser_ask_user: it asks the user to sign in, pass a CAPTCHA, click a control that ignores the agent, or choose (API reference).

    Targeted writes use strict selectors: a core tool's selector target must match one element. The Kitsune-owned tools apply the same rule to focus/blur, scroll, trusted clicks, fuzzy form-fill keys and implicit upload inputs, and take first=True to explicitly opt into the first match.
